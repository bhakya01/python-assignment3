# Python Programming Assignment – Loops, Control Statements & Functions

## 📌 Project Overview

This project focuses on implementing fundamental Python programming concepts, including loops, control statements, and functions.

The assignment includes three practical programs:

1. Number Guessing Game
2. Multiplication Table Generator
3. BMI Calculator

The main objective is to develop programming logic, understand control flow, and apply Python concepts to real-world examples.

## 🎯 Learning Objectives

* Understand iteration using `while` and `for` loops.
* Learn control statements such as `break`, `continue`, `pass`, and `else`.
* Create and use functions in Python.
* Practice user input and output.
* Develop logical problem-solving skills.

## 📝 Tasks Included

### 🔹 Task 1: Number Guessing Game

**Topic:** While Loop & Control Statements

A Python game that generates a random number between 1 and 10. The user gets a maximum of 3 attempts to guess the correct number.

**Features:**

* Generates a random number using `random.randint()`.
* Allows 3 guessing attempts.
* Checks whether the guess is within the range of 1 to 10.
* Displays messages for guesses that are too high or too low.
* Uses `continue` for invalid guesses.
* Uses `break` when the correct number is guessed.
* Uses `else` with the while loop when attempts are exhausted.

**Concepts Used:**

* While loop
* If-elif-else
* Break
* Continue
* Random module

### 🔹 Task 2: Multiplication Table Generator

**Topic:** For Loop & Range Function

A Python program that generates a multiplication table from 1 to 10 for a number entered by the user.

**Features:**

* Accepts a number from the user.
* Uses a `for` loop.
* Uses the `range()` function.
* Calculates multiplication results.
* Displays the table in a structured format.

**Concepts Used:**

* For loop
* Range function
* User input
* Arithmetic operators

### 🔹 Task 3: BMI Calculator

**Topic:** Functions & Arithmetic Operations

A Python program that calculates Body Mass Index (BMI) using the user's weight and height.

**Formula:**

BMI = Weight (kg) / Height (m)²

**Features:**

* Defines a `calculate_bmi(weight, height)` function.
* Accepts weight in kilograms.
* Accepts height in meters.
* Calculates and displays the BMI.
* Formats the result to two decimal places.

**Concepts Used:**

* Function definition
* Function parameters
* Return statement
* User input
* Arithmetic operations
